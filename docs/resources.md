# 学习资源

优先级：官方文档 > 源码与规范 > 高质量系统文章 > 视频课程。

## Java

- Dev.java：Java 语言与新特性。
- OpenJDK 文档：集合、并发包和 JVM 参数。
- 《Java 并发编程实战》：线程安全、锁和并发容器。
- 《深入理解 Java 虚拟机》：JVM 内存、GC 和类加载。

## Spring 与微服务

- Spring Boot Reference：配置、MVC、测试、Actuator。
- Spring Cloud Reference：Gateway、LoadBalancer 和 OpenFeign。
- Spring Cloud Alibaba：Nacos、Sentinel 和版本说明。
- Spring AI Reference：ChatClient、Advisor、RAG、VectorStore 和 Observability。

## 数据与中间件

- MySQL 8.0 Reference Manual：索引、事务、MVCC 和 `EXPLAIN`。
- Redis Documentation：数据结构、淘汰、持久化和缓存模式。
- RabbitMQ Documentation：Publisher Confirm、消费确认、重试和死信。
- Qdrant Documentation：Collection、Payload 过滤、混合查询和 Snapshot。
- MinIO Documentation：Bucket、对象 Key 和生命周期。

## AI 与 RAG

- Spring AI RAG 与 Advisors 文档。
- Qdrant Hybrid Search 与 RRF 文档。
- 国内模型 API 的 OpenAI 兼容接口文档。
- Ollama 模型和 Embedding 使用说明。

## 算法

- LeetCode Hot 100。
- 按数组、哈希、双指针、滑动窗口、链表、栈队列、二分、树、图、回溯、DP、堆和贪心分类复盘。

## 使用规则

- 每个主题先写“我能回答的三个问题”，再阅读。
- 不收藏未处理资料。
- 官方示例必须在本机运行并改成自己的业务场景。
- 每周至少记录一次源码阅读结论。
