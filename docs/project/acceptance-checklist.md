# 阶段验收清单

阶段门禁未通过时，不进入下一阶段。每个结论必须有测试、日志、报告或演示链接作为证据。

## 通用工程门槛

- [ ] 所有构建均可使用一条命令完成。
- [ ] 所有测试可重复运行，不依赖本机预置数据。
- [ ] 没有明文密钥、账号或私有文档。
- [ ] 每个服务都有健康检查和启动说明。
- [ ] 统一错误体包含 `code`、`message`、`traceId` 和 `details`。
- [ ] 关键日志不打印完整 Prompt、文件内容和访问令牌。

## W4：Spring Boot 与数据库基础

- [ ] REST 服务支持参数校验、业务异常、未知异常和请求 ID。
- [ ] MySQL Schema 由 Flyway 管理。
- [ ] MyBatis 查询有分页和条件过滤。
- [ ] Testcontainers 集成测试通过。
- [ ] Docker Compose 可启动应用和 MySQL。
- [ ] 能通过 `EXPLAIN` 解释一次查询的索引使用情况。

## W8：微服务与异步摄取

- [ ] 六个服务均注册到 Nacos。
- [ ] 通过 Gateway 至少访问两个下游服务。
- [ ] JWT、Workspace 和 RBAC 验证通过。
- [ ] 跨 Workspace 访问被拒绝并有自动化测试。
- [ ] 文档可上传到 MinIO。
- [ ] RabbitMQ 重复事件不会重复创建任务。
- [ ] 文档可完成 `UPLOADED → READY`，失败时可进入 `FAILED`。
- [ ] 至少摄取 10 份中文公开文档。

## W12：RAG 主链路

- [ ] Qdrant 同时保存 Dense 和 Sparse 向量。
- [ ] 混合检索使用 RRF 并返回稳定引用。
- [ ] 检索始终过滤当前 Workspace。
- [ ] SSE 能返回 Token、引用、完成和错误事件。
- [ ] 会话可连续提问并使用裁剪后的记忆。
- [ ] Prompt 模板有版本，消息记录使用版本。
- [ ] 国内模型 API 和 Ollama 可通过统一模型接口切换。
- [ ] RAG 端到端集成测试通过。

## W15：公网部署

- [ ] 六服务在 2C4G 环境健康运行。
- [ ] 上传、检索、流式聊天和引用公网可用。
- [ ] HTTPS 和基础安全响应头已配置。
- [ ] CI 执行测试、构建镜像和依赖扫描。
- [ ] 镜像发布到 GHCR。
- [ ] 服务器重启后数据可恢复。
- [ ] 1 小时内无持续 OOM 和异常重启。

## W18：作品集

- [ ] 架构图、部署图和两个关键时序图完整。
- [ ] README 可让陌生人完成本地启动。
- [ ] 有演示账号和 2–5 分钟演示视频。
- [ ] 有 30 条黄金问答、Hit@5 和延迟报告。
- [ ] 有并发上传、重复消息和模型故障报告。
- [ ] 有 50 并发压测报告和优化前后对比。
- [ ] 简历中每项成果都能定位到证据。
- [ ] 能完成 8 分钟项目讲解和 15 个项目追问。

## 关键测试场景

- [ ] 同一文档事件消费多次，只保留一套有效 Chunk。
- [ ] Workspace A 无法检索 Workspace B 的文档。
- [ ] 国内模型超时后切换到 Ollama。
- [ ] 模型网关不可用时 SSE 返回稳定错误，不挂起连接。
- [ ] SSE 客户端断开后服务端释放资源。
- [ ] 文档解析失败有原因、重试次数和终止状态。
- [ ] PDF 页眉页脚不会造成大面积重复 Chunk。
- [ ] Embedding 维度变化时启动校验失败，不写入脏向量。
- [ ] 50 并发请求下错误率、P95 延迟和内存使用有记录。
