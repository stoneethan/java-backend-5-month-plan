# W1 闭卷诊断

先限定 60 分钟闭卷完成，再对照官方文档检查。不要边做边问 AI。

## Java

1. 解释 `ArrayList`、`LinkedList`、`HashMap`、`ConcurrentHashMap` 的主要数据结构和适用场景。
2. 写代码统计字符串中每个字符出现次数，并按次数倒序输出。
3. 写出一个线程池创建示例，并解释核心线程数、最大线程数、队列和拒绝策略。
4. 解释受检异常和运行时异常的差异，并给出业务异常设计建议。
5. 写出一个使用 Stream 对对象列表分组、过滤和排序的例子。

## SQL

给定 `users`、`orders`、`order_items` 三张表：

1. 查询每个用户最近一笔订单。
2. 统计最近 30 天每个用户的有效订单金额。
3. 找出订单数量排名前 10 的用户。
4. 解释 `WHERE`、`GROUP BY`、`HAVING`、`ORDER BY` 的执行顺序。
5. 对一条慢查询写出 `EXPLAIN` 分析思路。
